LotKeys Drive Test v0.9.3.3
Build query: ?build=0933

Connection + video upload update:
- Header readiness, version/status card, and Garage Store status now use the same live connection state.
- A restored healthy Store session automatically advances the version card to green Authorized; no Refresh Status tap is required.
- Healthy Store connections show Connected to Store ✓ instead of an active Reconnect button.
- Reconnect to Store appears only when a saved Store exists but Google/Drive authorization needs recovery.
- Video uploads now use adaptive large resumable chunks: up to 128 MiB on fast connections instead of fixed 8 MiB chunks.
- Large video chunks report live XHR upload progress while durable Drive checkpoints remain resumable.
- When only a video changes, unchanged Photos/Documents media folders are skipped so video transfer begins sooner.
- A temporary screen wake lock is requested during active video transfer when supported to reduce accidental screen-lock pauses.
- Existing paused/resumable upload behavior remains intact.
