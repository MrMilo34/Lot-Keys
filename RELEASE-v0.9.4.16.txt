LotKeys v0.9.4.16 — FULL RELEASE
=================================

Source base
-----------
This release is built from the exact current MrMilo34/Lot-Keys main branch (v0.9.4.15 + the prior 0.9.4.15.1 service-worker hotfix), so Management Updates, image/video blocks, Top Contributors, Facebook Assistant support, Inventory, Listings, Garage/Admin, Account, media upload, and all other current source files are preserved.

Primary fix — durable cross-device Listing reconciliation
---------------------------------------------------------
- Listings left local / pending / syncing / error are retried whenever Google Drive becomes usable.
- Recovery repeats on startup, focus, page resume, reconnect/online, visibility return, and periodically while LotKeys is open.
- A Listing that says Synced but its Drive file is missing or in the wrong Listings folder is repaired and re-uploaded.
- Manual/automatic Listing refresh checks the actual Drive folder instead of trusting Listings Index.json as authoritative.
- Duplicate or legacy Store / Users / <User> / Listings folders are detected. Listing records are merged into one deterministic canonical folder and the device's cached structure is corrected.
- The canonical folder is scanned with a full refresh after reconciliation, rebuilding Listings Index.json from actual Listing files.
- Existing Listing IDs, Facebook URLs, statuses, photo order, descriptions and local records are preserved; the goal is to recover stranded records such as the Q50 RedSport and Ram 1500 instead of asking the user to recreate them.

Deployment
----------
This branch/archive is a complete release. Replace the existing GitHub Pages repository files with the contents of this release (not just sw.js), commit, then open LotKeys on the phone first and reload once. After the phone reaches a green Authorized state, open/reload LotKeys on the desktop. The phone should push any stranded local Listings and both devices should converge on the same Drive records.
