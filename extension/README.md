# LotKeys Facebook Posting Buddy

Current beta: **V0.1.22**

V0.1.22 keeps the speed-first horizontal **Video · Photos · Description · Details** workflow and the V0.1.21 chunked large-video handoff. Existing-listing photo updates are now full replacements: Posting Buddy prepares the complete LotKeys photo selection, removes the old Facebook photos, then uploads the LotKeys set in its saved order. Selected Model, Mileage, Price and Description values are cleared before replacement.

If Facebook does not expose safe photo-removal controls, Posting Buddy leaves the live photo set untouched for manual review instead of risking duplicates.
